v1.8 변경사항

  • 오늘의 디시플린 카드 — 접속하면 상단에 시장 상태 맞춤 매매 규율 한 줄(약세=현금도 포지션, FOMO 과다=추격 금지, 강세=손절가 먼저 등) + 🔥 연속 사용일. 데이터 누적 습관을 게임화하고, 그날 가장 필요한 마인드셋을 띄웁니다
  • 충동 금고 (쿨다운) — 섹터 상세에서 🔒 버튼으로 '지금 사고 싶은 이유'를 봉인 → 20시간 뒤 그 사이 누적 등락과 함께 "지금도 사고 싶은가?"로 다시 묻습니다. 추격매수를 하루 식히는 행동재무학 장치. 오늘 탭 하단에서 확인·정리
  • 두 기능 모두 차트·외부데이터 없이 작동하며, 개인투자자 최대 적인 충동매매·뇌동매매를 겨냥합니다

v1.7 변경사항

  • 시스템 자가 채점 — 어제 '살 후보(S·A)'로 꼽힌 섹터가 다음 거래일에 실제 올랐는지 매일 자동 채점. 누적 적중률 + 평균 익일 수익 + 최근 8건 결과를 장 판단 아래에 표시. 확증편향 방어이자 시스템 신뢰도의 데이터 증명
  • 섹터 생애주기 6단계 — 태동 → 가속 → 성숙 → 과열 → 둔화 → 소외. 누적·가속·강도·확산·순위를 묶어 각 섹터를 단계로 분류. 진입(태동·가속) / 보유(성숙) / 청산(과열·둔화) 타이밍을 한 단어로
  • 시장 폭 게이지 — 개별 섹터가 아닌 전체 장의 상승 폭(advancing %)·평균 Breadth를 0~100 점수 + 10일 스파크라인으로. 저점→급반등 시 '확산 스러스트' 강세 신호 자동 감지. "오늘 공격해도 되는 장인가"의 매크로 판단

v1.6 변경사항

  • 오늘의 액션 보드 — 장 판단 바로 아래. 살 것 🟢 / 볼 것 🟡 / 피할 것 🔴 3분할 + 컨빅션 등급(S 적극 / A 분할 / B 관찰 / 추격금지 / 매도검토). 데이터(떠오름·강도·확산·순위·FOMO)로만 분류, 추측 배제
  • 밝은 한지 톤 전면 적용 — 일목 시스템과 동일 라이트 팔레트 + Pretendard. 등락은 한국식(상승 빨강/하락 파랑) 유지, 매수신호는 초록 분리축
  • 페이지 진입 자동 로딩 — 도움말 자동 팝업 제거, 열면 바로 데이터
  • 박스 오와열 정렬 — 업종/테마 패널·카드·스포트라이트 높이 통일

v1.5 변경사항

  • 섹터 지형 매트릭스 — 강도 × 가속 4분면. 주도지속 / 떠오름 / 과열 / 소외를 한 화면에, 버블 크기는 거래대금
  • 오늘 브리핑 자동 작성 + 복사 — 판단·떠오름·식는·과열을 한 문단으로, 기록·블로그·에펨 글감
  • 시각 연출 — 떠오름 점수 카운트업, 카드 등장 애니메이션, 1순위 글로우 펄스

v1.4 변경사항

  • 지금 주목 대시보드 — 오늘 탭 최상단. 장 판단 한 줄 + 떠오름 Top 3 + 식어가는 칩
  • 떠오름 점수(0~100) — 가속·신규·확산·국면 결합. "이미 오른 것" 아닌 "막 시작하는 것" 추출
  • 매수 신호 = 테두리·게이지로 분리, 등락 색(한국식)과 충돌 제거
  • 식어가는 섹터에서 관심종목 섹터 자동 강조

오늘의 디시플린 카드

접속하면 상단에 오늘의 매매 규율 한 줄이 시장 상태에 맞춰 바뀝니다. 옆의 🔥는 연속 사용일 — 이 시스템은 데이터가 매일 쌓일수록 정확해지므로, 매일 한 번 여는 습관 자체가 성과로 이어집니다.

약세 위축
"현금도 포지션. 신규 진입은 한 박자 쉬어가자"
FOMO 과다
"추격은 가장 비싼 표 — 다음 기회를"
강세 확산
"살 건 사되, 손절가(R)부터 정하라"
적중률 저조
"시스템 헛발질 구간 — 관망하며 기준 점검"

충동 금고 (쿨다운)

섹터 상세를 보다 "지금 사고 싶다"는 마음이 들면 🔒 버튼으로 이유를 적어 봉인합니다. 20시간 뒤 '오늘' 탭 충동 금고에서 그 사이 누적 등락과 함께 다시 보여주며 "지금도 사고 싶은가?"를 묻습니다.

  • 봉인 직후엔 🔒 잠김(남은 시간 표시) → 20시간 경과 시 🔓 재평가 가능
  • 재평가에서 확신이면 해제, 충동이었으면 버림 — 어느 쪽이든 그 사이 등락이 판단을 도와줍니다
  • 핵심: 충동과 확신을 가르는 건 '하루'라는 시간. 봉인 자체가 추격매수를 막는 안전장치입니다

두 기능 모두 기기 localStorage에 저장되며, 설정 탭 JSON 내보내기에는 포함되지 않는 가벼운 보조 장치입니다.

★ v1.7 신규 — 성적표 · 생애주기 · 시장 폭

시스템 자가 채점 (적중률)

장 판단 바로 아래 성적표는 어제 '살 후보(S·A)'로 꼽힌 섹터가 다음 거래일에 실제로 올랐는지를 매일 자동 채점합니다. 누적 적중률·평균 익일 수익·최근 8건 결과(초록=적중/파랑=빗나감)를 보여줍니다.

  • 이틀 이상 새로고침해야 채점 시작 (오늘 추천은 내일 채점)
  • 적중률 60%↑ 초록 / 45~60% 노랑 / 그 아래 파랑
  • 용도: 시스템을 믿어도 되는지 데이터로 검증 + 확증편향 방어. 적중률이 낮게 누적되면 등급 기준이 형님 장세와 안 맞는다는 신호 → 기준 재점검

섹터 생애주기 6단계

매트릭스 아래 띠는 모든 섹터를 흐름 순으로 분류합니다. 차트가 아니라 누적·가속·강도·확산·순위의 조합 판정입니다.

태동
가속 붙기 시작 + 확산 양전 — 관찰·소량 진입 후보
가속
가속 강함 + 누적 양수/순위 상승 — 분할 진입 적기
성숙
강도 높음 + 가속 유지 — 보유 유지, 신규는 분할
과열
5일 누적 과다(FOMO) + 가속 둔화 — 추격 금지·차익 분할
둔화
가속 음전 또는 순위 ▼5↑ — 보유 1차 매도 검토
소외
약하고 둔화 — 관심 밖

자금이 어느 단계에 몰려 있는지(태동·가속 칸이 두꺼우면 초기 강세장, 과열·둔화가 두꺼우면 후반)를 한눈에 봅니다.

시장 폭 게이지 (Breadth Thrust)

개별 섹터가 아니라 전체 장의 상승 폭입니다. 상승섹터 비율 60% + 평균 Breadth 40%를 0~100 점수로, 10일 스파크라인과 함께 표시합니다.

  • 65↑ 강세 확산 / 50~65 완만한 강세 / 38~50 중립 / 그 아래 약세 위축
  • 확산 스러스트 ↑: 저점(상승비율 ≤42%)에서 단기에 60%↑로 급반등 = 강세장 시작 조기 신호 (Zweig Breadth Thrust 개념)
  • 위축 신호 ↓: 고점에서 급락 = 폭이 무너지는 중
  • 용도: 액션보드가 '공격'이라도 시장 폭이 약세 위축이면 한 박자 보수적으로 — 매크로 안전판
★ 오늘의 액션 보드 (v1.6 신규)

이게 뭔가

장 판단 바로 아래에서 오늘 섹터를 살 것 / 볼 것 / 피할 것 3개로 분류합니다. "어디를 볼지"를 넘어 "무엇을 할지"까지 데이터로 정리하는 자리. 차트·캔들은 일절 안 쓰고, 떠오름·강도·확산(Breadth)·순위변화·FOMO만으로 판정합니다.

컨빅션 등급

S 적극
떠오름 ≥ 62 & 강도 ≥ 55 & 확산 ≥ +0.3 & 과열 아님 — 4박자. 풀사이즈 검토 후보
A 분할
떠오름 ≥ 48 & 과열 아님 — 모멘텀 확실. 분할 진입 후보
B 관찰
떠오름 ≥ 32 — 관찰권. 확산 약하면 가짜 의심 표시
매도 검토
순위 ▼5↑ & 관심종목(★) 보유 섹터 — 1차 매도 알람
추격 금지
5일 누적 +15%↑ 과열 — 신규 추격 위험

3개 컬럼

  • 🟢 지금 살 후보 — S·A 등급. 컨빅션(떠오름) 순으로 1~5위 번호. 위에서부터 우선순위.
  • 🟡 지켜볼 것 — B 등급. 아직 확신은 부족, 하루이틀 더 관찰.
  • 🔴 피할 것 / 정리 — 과열(추격금지) + 식어가는(매도검토). 관심종목 보유 섹터가 식으면 우선 표시.

중요: 등급은 후행 데이터 기반 분류입니다. 실제 진입은 R-multiple·Kelly·손절가를 따로 계산하세요. 보드는 "오늘 손댈 후보 리스트"를 좁혀줄 뿐, 매수 버튼이 아닙니다.

떠오름 점수 (0~100)

"이미 많이 오른 섹터"가 아니라 막 가속이 붙기 시작한 섹터를 잡는 점수입니다. 스윙~추세(5~10일) 관점.

가속 (40)
오르는 속도가 빨라지는 중인가 — 가장 선행
신규 (25)
순위가 새로 치고 올라왔는가 (NEW·▲)
확산 (25)
섹터 내 다수가 같이 오르는가 (Breadth)
국면 (±10)

색의 의미

  • 초록 테두리·게이지 = 공격 후보 (막 시작)
  • 노랑 테두리·게이지 = 이미 과열, 추격 주의
  • 등락률 숫자는 한국식(상승 빨강 / 하락 파랑). 매수 신호는 테두리·게이지·등급칩으로만 분리 표시.

2. 컬럼 / 지표 해설

Δ (델타 랭크)

어제 vs 오늘 순위 변화. 이 도구의 핵심 지표. Δ는 "자금이 어디로 이동했는가"를 직접 보여줌.

Breadth (브래드스)

(상승종목 − 하락종목) / (상승+하락). 범위 −1 ~ +1.

+0.5 이상
광범위 강세 — 진짜 주도섹터의 신호
0.0 근처
혼조 — 등락률이 +여도 대장주 한두 개가 끌고 가는 가짜
−0.5 이하
광범위 약세

핵심: 등락률 +1.5%지만 Breadth 0.1 = 가짜 / 등락률 +1.0%인데 Breadth 0.7 = 진짜.

가속도 (Accel)

(최근 절반 평균) − (이전 절반 평균). 양수 = 모멘텀 가속, 음수 = 둔화.

통합점수 (헤게모니 탭)

0~100 정규화. 오늘(25) + 5일추세(25) + Breadth(25) + 가속도(25). 70 이상 = 강력한 후보.
